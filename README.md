## Integrantes

- Nombre del compañero

## Descripción

Este proyecto contiene los ejercicios realizados para el laboratorio
de Collections y Generics en Java.

## Collections

Se desarrollaron 9 ejercicios utilizando diferentes estructuras
de datos de Java.

### Ejercicios

1. TreeSet de productos.
2. Stack con diferentes tipos.
3. Lista sin duplicados.
4. PriorityQueue de tareas.
5. HashMap, LinkedHashMap y TreeMap.
6. Inventario con ArrayList.
7. Cola de atención con LinkedList.
8. Historial de cambios con Vector.
9. Historial de navegación con Stack.

## Generics

Se desarrollaron 10 ejercicios sobre programación genérica.

### Nivel básico

1. Caja<T>.
2. Método mostrarElemento<T>.
3. Contenedor<T>.

### Nivel intermedio

4. CajaNumerica<T>.
5. Método sumar<T>.
6. Comparador<T>.

### Nivel avanzado

7. EntidadPersistente<T>.
8. Servicio<T>.
9. Ordenador<T>.
10. Calculadora genérica.

## Tecnologías utilizadas

- Java
- IntelliJ IDEA
- Maven
- JUnit

## Ejecución

Para ejecutar el proyecto se debe abrir en IntelliJ IDEA,
compilar el proyecto y ejecutar las clases correspondientes
a cada ejercicio.
